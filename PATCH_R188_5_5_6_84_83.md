# R188.5.5.6.84.83 — Fast Manifest Hot Path

Base: `R188.5.5.6.84.82`
Target: `R188.5.5.6.84.83`
Mode: overlay patch, NO_ASSETS compatible.

## Что исправлено

`asset_manifest.php` больше не строит полный инвентарь из eager CSS/JS, изображений и всех lazy-route ресурсов на каждом критическом boot-запросе.

Добавлены три режима ответа:

- `atomic_boot` — проверяет только 11 исполняемых boot JS-ресурсов. Опциональные изображения и lazy-route assets не способны заблокировать запуск приложения до первого кадра.
- `runtime_probe` — возвращает только release parity без обхода файловой системы.
- `route_loader` — отдаёт только CSS/JS lazy-route contract, без изображений, eager assets и приватных `_meta` / `_sourceLayers` записей.

Полный обычный manifest сохранён для deploy/diagnostic tooling и остаётся строгим по отсутствующим файлам.

## Route manifest cache

`js/next/route_asset_loader.js` больше не добавляет `Date.now()` к каждому запросу manifest и не использует `cache:'no-store'` для release-scoped route contract.

URL стабилен внутри release:

`/asset_manifest.php?v=188.5.5.6.84.83&route_loader=1`

Ответ имеет immutable cache policy, а Service Worker кэширует route manifest в `STATIC_CACHE`. Следующий документ того же release может использовать готовый route contract без повторной генерации полного manifest.

## Размер ответа локальной контрольной сборки

- старый/full manifest: ~82,373 B;
- atomic boot manifest: ~3,725 B;
- runtime watchdog probe: ~190 B;
- route-loader manifest: ~64,895 B.

Atomic response уменьшен примерно на 95%, runtime probe — более чем на 99%. Route manifest уменьшен примерно на 21% и теперь release-cacheable.

## Regression

Добавлен `tools/test_fast_manifest_hot_path_84_83.js`, который исполняет PHP manifest во всех режимах и проверяет:

- atomic boot не зависит от отсутствующих NO_ASSETS изображений;
- runtime probe не выполняет asset inventory;
- route-loader manifest не содержит изображений/private route metadata;
- route manifest больше не cache-bustится `Date.now()`;
- source `route_asset_loader.js` и generated `runtime_shell_bundle.js` синхронны;
- Service Worker кэширует versioned route manifest;
- version parity `.84.83`;
- frozen `index.php` hash не изменён.
