# KARETA.KZ — каталог кодов ошибок

Публичный код имеет формат `KRT-<ОБЛАСТЬ>-<НОМЕР>` и показывается пользователю без технического stack trace. Полная причина, версия и адрес страницы сохраняются в runtime/client error log.

Канонический источник кодов в приложении: `inc/error_codes.php`. Уже назначенный код нельзя использовать для другой причины.

| Код | Значение |
| --- | --- |
| `KRT-BOOT-1001` | Не удалось получить или подтвердить манифест файлов |
| `KRT-BOOT-1002` | Сервер вернул некорректный JSON манифеста |
| `KRT-BOOT-1003` | Версия HTML/клиента не совпадает с версией сервера |
| `KRT-BOOT-1004` | В сборке отсутствует обязательный runtime-файл |
| `KRT-BOOT-1005` | Runtime-модуль не загрузился по сети |
| `KRT-BOOT-1006` | Ошибка выполнения runtime-модуля |
| `KRT-BOOT-1007` | Тайм-аут загрузки приложения |
| `KRT-BOOT-1008` | Не загрузились критические стили |
| `KRT-BOOT-1009` | Не загрузился логотип |
| `KRT-BOOT-1010` | Не все runtime-модули запустились |
| `KRT-BOOT-1099` | Неизвестная ошибка запуска |

Следующие диапазоны зарезервированы: `AUTH` — авторизация, `API` — запросы API, `DB` — база данных, `UI` — интерфейс, `MSG` — Telegram/WhatsApp/чат.
