# KARETA.KZ UI LOCK RULES

Статус: обязательный UI-контракт с релиза 188.5.5.6.84.129.

## Замороженные зоны

1. Нижнее мобильное меню `#k-mobile-nav` не изменять:
   - не менять дизайн;
   - не менять состав пунктов;
   - не менять порядок пунктов;
   - не менять подписи, иконки и логику More;
   - не заменять существующую role/context navigation policy новым макетом.

2. Верхнюю шапку `#k-shell-header` не переделывать:
   - не менять высоту, фон, сетку, позицию логотипа;
   - не заменять существующий логотип;
   - не менять кнопку меню, уведомления и Back;
   - не добавлять новые брендовые wordmark-слои.

## Единственное разрешённое изменение шапки

Разрешена только иконка текущего города рядом с существующим логотипом:
- icon-only;
- текущий город: Усть-Каменогорск;
- визуально не перестраивает header;
- клик переводит к существующему выбору города на главной;
- текст города не занимает место в шапке.

Любые дальнейшие изменения клиентских страниц должны сохранять этот контракт.
