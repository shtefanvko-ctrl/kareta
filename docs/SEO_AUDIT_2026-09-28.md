# External SEO audit — 2026-09-28

Scope: public external behavior of `kareta.kz`, `www.kareta.kz`, and `s.kareta.kz`.

## Confirmed findings

### P0 — robots.txt is not a robots file
A live request to `https://kareta.kz/robots.txt` is handled by the SPA fallback and returns the application HTML with HTTP 200.

Required fix: serve a real `text/plain` robots file outside SPA routing.

### P0 — sitemap.xml is not an XML sitemap
A live request to `https://kareta.kz/sitemap.xml` is handled by the SPA fallback and returns the application HTML with HTTP 200.

Required fix: serve a valid XML sitemap containing only canonical, indexable public URLs.

### P0 — stale www host / canonical split
Search-index evidence still contains an older landing page under `www.kareta.kz`, while a fresh external DNS fetch cannot resolve that hostname.

Required fix: restore DNS for `www` and permanently redirect it to `https://kareta.kz/`. Do not maintain separate content on both hosts.

### P1 — hash-only public navigation
External URL mapping discovers only the root document. Public product navigation is predominantly represented as `#/...` fragments.

Required fix: expose indexable public entities under ordinary paths with server-readable HTML/meta. Keep private/authenticated screens excluded.

### P1 — missing page-level SEO metadata
The live root HTML contains a title and meta description, but the audit did not find:
- canonical link;
- Open Graph metadata;
- Twitter Card metadata;
- hreflang;
- JSON-LD Schema.org markup.

Add metadata only when it accurately represents real page content and entities. Do not publish fabricated ratings, reviews, prices, or availability.

### Stage environment
`https://s.kareta.kz/` currently returns HTTP 403 to an external crawler. That keeps the stage environment out of normal indexing, which is acceptable. Production sitemap/canonical references must never point to stage.

## Verification after implementation

1. Fetch `/robots.txt` and verify status, MIME type and directives.
2. Fetch `/sitemap.xml` and validate XML plus every listed URL.
3. Verify HTTP and HTTPS `www` permanently redirect to the apex host.
4. Verify every indexable public route returns unique server-readable title, description and canonical.
5. Re-map the site with an external crawler and confirm more than the single root URL is discoverable.
6. Validate structured data and social previews.
7. Confirm stage remains excluded from production indexing.
