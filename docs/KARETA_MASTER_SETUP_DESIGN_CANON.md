# Дополнение к канону KARETA: настройки Мастера

Дата: 01.10.2026. Основание: решения пользователя в текущем задании. Статус: согласованный продуктовый подход; реализация в feature-ветке; проверку устройств выполняет пользователь.

## Связь с действующим каноном

Основные ограничения: [KARETA_UI_LOCK_RULES.md](KARETA_UI_LOCK_RULES.md). Геометрия действующего интерфейса: css/next/master_shell_canonical_84_143.css и css/next/page_geometry_canonical_84_146.css. Шапка, логотип и меню сохраняют действующие контракты. Дополнение относится к содержимому раздела «Мои услуги» и его окну настройки.

## Согласованные правила

- Настройка похожа на выбор музыкальных жанров: визуальные категории, затем конкретные услуги. Выбранное явно отмечено, можно настроить несколько направлений.
- Оборудование выбирается как набор инструментов в игре: категории → карточки → способ доступа. Выбранные инструменты собираются в нижнем доке.
- Основной выбор выполняется кнопками без обязательного набора текста. Встроенный редактор цен и времени доступен отдельно.
- В карточке есть изображение SVG, иконка и короткое название. Один смысл новых карточек использует один ID иконки. Меню использует прежние ID и SVG.
- На телефоне карточки компактны; на планшете крупнее. Для нового окна текущий CSS задаёт 2 колонки до 600px, 3 далее и 4 с 900px; это реализация, которую нужно проверить на устройствах.
- Локальные шаги настройки показаны кругами. Они не изменяют счётчик основной заявки. Клиентская заявка в проверенном исходнике имеет 5 шагов; мастерская — 4.
- Каждое изменение отправляется на сохранение. «Сохранено» появляется после ответа сервера. При ошибке показывается ошибка, выбор хранится как черновик текущего профиля.
- При конфликте основной остаётся сохранённая серверная версия. Черновик не перезаписывает её автоматически: «Оставить сохранённое» убирает конфликт без записи в профиль; «Мой черновик» применяет выбор только по отдельному нажатию с актуальной ревизией. Во время нерешённого конфликта новый выбор блокируется, чтобы не потерять обе версии.
- Черновик текущей реализации хранится в sessionStorage: он переживает обновление страницы в этой вкладке, но не гарантирует восстановление после закрытия вкладки/браузера или на другом устройстве. Подтверждённые сервером данные подгружаются из профиля.
- Повторный вход подгружает сохранённые услуги/оборудование. Контексты аккаунтов разделены; поздний ответ закрытого окна не обновляет новое.
- Доступ к оборудованию: «Есть» / «В СТО» / «Арендую» / «Нужно купить». Последнее состояние не означает наличие оборудования.
- Оборудование не подтверждает квалификацию автоматически. Его связь с услугами требует экспертной проверки перед жёсткими ограничениями подбора.
- Декоративные движения короткие; системное уменьшение анимации учитывается. Выбор доступен обычным нажатием, без обязательного перетаскивания.

## Источники истины

Услуги: существующий service_catalog и service_offers, те же service ID. Оборудование в feature-ветке: storage/catalog/master_equipment.json; выбор хранится в person_profiles.payload_json.masterEquipment текущего авторизованного профиля. Маршрут: существующий #/services/manage, без второго роутера.

Иконки: KaretaUIIcons, дополненные локальным набором Tabler v3.48.0 (MIT). 39 SVG и sprite лежат в assets/icons/tabler. Список доступной полной библиотеки является справочным индексом, не стартовой загрузкой.
