## 1. Принципы

1. Белый — базовая поверхность; графит и глубокие тёмные тона — читаемые тексты; оранжевый — фирменный знак и главный action. Тёмная тема имеет **свои пары**, но не меняет логику и ID компонентов.
2. Никаких фиолетовых/синих кнопок вместо оранжевых, необоснованных градиентов, поддельных логотипов и смешивания разных иконочных библиотек.
3. Контраст рассчитывается **относительно реального фона**. Текст: WCAG 2.2 AA **4.5:1** (обычный) / **3:1** (крупный ≥24 CSS px или ≥18.66 px bold); значимая графика и UI-границы: **3:1**. Для более надёжных сочетаний производные цвета рассчитываются до ≥5.25:1 против эталонной поверхности.
4. Значения в `color_tokens_v3.json` — **кандидатные семантические токены**, не подмена действующих CSS-переменных. Пары и матрица — в CSV. Цвет никогда не является единственным носителем состояния.

## 3. Математика, а не «подбор на глаз»

Для каждого sRGB-канала `c` в диапазоне 0…1: `linear(c) = c/12.92` при `c <= 0.04045`, иначе `((c+0.055)/1.055)^2.4`. Относительная яркость `L = 0.2126R + 0.7152G + 0.0722B`. Контраст `CR=(max(L1,L2)+0.05)/(min(L1,L2)+0.05)`. Все числа ниже вычислены из **точных 8-битных HEX** (а не приблизительных HSL).

При получении текстовой версии статуса базовый H/S исходного цвета сохраняется, меняется только HSL Lightness бинарным поиском до порога ≥5.25 к белому (light) или тёмной карточке (dark). Слой выделения вычисляется прямым alpha-compositing исходного оранжевого на белом (8% или 14%). Это **вычислимые производные** — не новые фирменные цвета логотипа.

| Значение | Оригинал | Для текста на белом (>=5.25) | Контраст к white | К soft | В тёмной карточке | Контраст к dark card |
|---|---|---|---:|---:|---|---:|
| orange | `#FC6606` | `#B84902` | 5.261:1 | 4.904:1 | `#FC6606` | 5.543:1 |
| success | `#16A34A` | `#117C39` | 5.295:1 | 4.936:1 | `#17A84C` | 5.306:1 |
| danger | `#DC2626` | `#D22222` | 5.260:1 | 4.904:1 | `#E76B6B` | 5.284:1 |
| warning | `#F59E0B` | `#966006` | 5.286:1 | 4.928:1 | `#F59E0B` | 7.696:1 |
| geo | `#06B6D4` | `#04768A` | 5.298:1 | 4.939:1 | `#06B6D4` | 6.808:1 |
| legacy_blue | `#2563EB` | `#2361EB` | 5.275:1 | 4.918:1 | `#628FF1` | 5.288:1 |

**Фиксированные выделения:** 8% orange + 92% white = `#FFF3EB`; 14% orange + 86% white = `#FFEADC`. Контур выделения — `#B84902`, не тёплый пастельный фон.

## 5. Полная cross-matrix

Источник полных чисел: [`contrast_matrix_v3.csv`](contrast_matrix_v3.csv). В таблице значения ≥4.5 соответствуют обычному тексту AA, 3–4.49 только крупному тексту/значимому UI, <3 нельзя использовать как единственный визуальный сигнал. Проверять реальный background элемента с учётом прозрачности, картинки и градиента.

## 6. Роли интерфейса, состояния, карты

| Поверхность | Фон | Текст | Акцент / контур |
|---|---|---|---|
| Светлый базовый | `#FFFFFF` / `#F7F7F5` | `#0B1220` / `#667085` | action `#B84902`, selected border `#B84902` |
| Тёмный базовый | `#0B1220` / `#1B1F26` | `#FFFFFF` / `#D7DEE8` | action `#FC6606`, action text `#0B1220` |
| Успех | нейтральный фон | light text `#117C39`; dark text `#17A84C` | icon + «Готово» |
| Ошибка | нейтральный фон | light text `#D22222`; dark text `#E76B6B` | icon + «Ошибка» |
| Предупреждение | нейтральный фон | light text `#966006`; dark text `#F59E0B` | icon + «Внимание» |
| Гео и OBD | нейтральный фон | light text `#04768A`; dark text `#06B6D4` | иконка pin / scan, подпись категории |

Карта: клиент/мастер/СТО/магазин/эвакуатор/мойка различаются **формой и пиктограммой**, а не шестью случайными цветами. Цвета статусов: только актуально доступен / ожидает / ошибка. Точка геолокации пользователя — отличается формой и подписью от бизнес-пинов. Маршрут — нейтральный трек с гео-акцентом. Радиус выезда показывать полупрозрачной областью с подписью и обязательно учитывать контраст на карте.

## 7. Логотип, типографика, геометрия

- Логотип: использовать файлы проекта, **не** перерисовывать SVG по памяти, не растягивать. Применять полную версию на landing/auth и компактную утверждённую пиктограмму там, где нет места.
- Типографика: Manrope/Inter/system fallback по текущей поверхности. Основной мобильный текст ≥16px; кнопка ≥15px; контент по RU/KK/EN, не впихивать строки в фиксированную ширину.
- Радиусы: существующий `css/next/design_contract.css` (xs 5px, control 10px, card 18px, dialog 24px). Отступы 4/8/12/16/20/24/32 px. Touch target ≥44×44 CSS px, предпочтительно 48.
- Приоритет — карточки и действия без визуального шума, вертикальный скролл, отдельная иконка `!` для пояснений, keyboard focus, reduced motion.

| Новая категория | SVG | Значение / ключ |
|---|---|---|
| Клиент | `assets/icons/kareta/client.svg` | `client` |
| Автосервис | `assets/icons/kareta/auto-service.svg` | `auto-service` |
| Автоуслуги | `assets/icons/kareta/auto-services.svg` | `auto-services` |
| Автотовары | `assets/icons/kareta/auto-goods.svg` | `auto-goods` |

- SVG: `viewBox="0 0 24 24"`, line outline, `fill="none"`, `stroke="currentColor"`, `stroke-width="1.9"`, `stroke-linecap="round"`, `stroke-linejoin="round"`; единая оптическая сетка/поля. Сохранять таблицы соответствия смысл → icon ID.
- Цвет задаётся **контекстом** через `color`/CSS-переменную; не вписывать брендовые hex в каждый path. Никаких сторонних URL, CSS filter recoloring, inline JS, foreignObject, data URI, дубликатов готовых логотипов автопроизводителей.
- Иконка не заменяет текстовую подпись; selected/disabled/error имеют текст и доступные aria-label/aria-pressed. Поддерживать размер 16/18/22/28 и touch box 44 px, согласно `css/next/icon_standard.css`.
- Существующие 39 Tabler SVG: лицензия MIT и происхождение в `assets/icons/tabler/LICENSE` и `index.json`; при публикации сохранять атрибуцию. Не заявлять о собственном авторстве этих глифов.

## 9. Вход и регистрация — дизайн, не изменение Identity

Выбор направлений для обсуждаемого первого экрана: **Клиент / Автосервис / Автоуслуги / Автотовары**. Бизнес может отметить несколько сфер, но identity/roleIntent разрешается **сервером** и не создаёт дополнительный Account. Это проектная гипотеза UI, а не разрешение обойти действующие auth/OTP/Identity gates. Нельзя менять текущую маршрутизацию и бизнес-контексты только ради оформления.
