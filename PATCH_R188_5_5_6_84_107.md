# KARETA.KZ — R188.5.5.6.84.107 — MASTER HOME STRUCTURE

## Task 101

The `#/master` home page now has one immutable seven-block structure:

1. Header
2. Статус приёма
3. Быстрые действия
4. Мои заявки
5. Заметки
6. Заявки на паузе
7. Сегодня

`MASTER_HOME_BLOCK_ORDER` is frozen and is the only source of block ordering in `renderData()`.
API responses and saved workplace visibility preferences can update data inside the blocks but can no longer remove or reorder the approved home structure after loading.

### Data mapping

- `Мои заявки` — active Master orders.
- `Заявки на паузе` — `waitingOrders` (`waiting_parts`, `waiting_approval`, `pending`).
- `Сегодня` — `todayOrders`.
- `Заметки` — permanent structural slot, ready for the dedicated notes task/API.
