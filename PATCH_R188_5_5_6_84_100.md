# KARETA.KZ R188.5.5.6.84.100 — Master UI polish

## Цель
Вторая волна очистки интерфейса Мастера: убрать оставшиеся повторы, снизить визуальный шум и исправить мобильную геометрию без изменения API/БД/маршрутов.

## Изменения
- Главная Мастера: мобильная панель исправлена с 3 колонок на 2 фактических действия.
- Главная Мастера: удалены мёртвые настройки/переменные старого окна Биржи, сокращён текст оперативной ленты.
- Аккаунт Мастера: удалена вторая кнопка «Публичный профиль» из шапки; осталось одно действие в сетке.
- Аккаунт Мастера: сетка стабилизирована как 2×2 на широких экранах и 1 колонка на мобильных.
- Биржа: по умолчанию показываются заявки по «Моим услугам»; весь поток остаётся доступен отдельной кнопкой.
- Биржа: техническое описание заменено на пользовательское.
- Мои услуги: 3 служебных счётчика сокращены до 2 полезных — «оказываю» и «опубликовано».
- Мои услуги: поясняющая боковая панель скрывается на узком мобильном экране; выключенные строки визуально тише.
- Ещё (Мастер): скрыта дополнительная карточка поддержки; окно содержит только согласованные 6 инструментов.
- Boot shell bundle пересобран после изменения Smart Action Hub.

## Не изменено
- Нижнее меню: Главная / Биржа / Услуги / Запчасти / Аккаунт / Ещё.
- API, БД, заявки, отклики, тарифы, каталоги и маршруты.
- Страница Запчастей: сохранена как единый Marketplace, так как её элементы не дублируют мастерскую навигацию.
