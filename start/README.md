# KARETA Start Landing

Изолированный публичный лендинг KARETA.KZ.

## Назначение

- отдельная папка `/start/`;
- не меняет текущий `index.php`, SPA router, service worker, asset manifest или API;
- использует канонические существующие логотип и onboarding-изображение из `../assets/`;
- адаптивен для телефона, планшета и desktop;
- RU / KK / EN;
- кнопки Android, iOS и Web.

## Файлы

- `index.html` — структура лендинга;
- `styles.css` — полностью локальные стили лендинга;
- `app.js` — переключение языка и обработка download-ссылок;
- `config.js` — единственное место для URL приложений.

## Download URLs

Сейчас в репозитории не найден канонический APK, Google Play URL или App Store URL, поэтому ссылки Android/iOS намеренно не выдуманы и показывают «Скоро».

После публикации приложений заполнить:

```js
window.KARETA_START_CONFIG = Object.freeze({
  webUrl: "../",
  androidUrl: "https://...",
  iosUrl: "https://..."
});
```

## Проверка

Открыть `/start/` через обычный HTTP(S)-сервер. Проверить:

1. desktop 1366+;
2. mobile 390x844;
3. RU → KK → EN;
4. Web button открывает текущую KARETA SPA;
5. Android/iOS остаются disabled, пока URL пустые;
6. после задания URL кнопка становится активной и открывает ссылку в новой вкладке.

## Изоляция

Этот модуль специально не включён в основной runtime и может разрабатываться/деплоиться независимо. Для перевода корневого домена на лендинг потребуется отдельное решение по маршрутизации/хостингу после проверки.
