## Продуктовые правила

1. Настройки как выбор жанров: категория → конкретные услуги. Для оборудования: категория → инструмент → доступ. Крупные визуальные карточки, короткие названия, нижний док выбранного.
2. Основной выбор кнопками. Цена/время доступны отдельным редактором. Пользователь может вернуться и продолжить.
3. Каждый выбор сохраняется; статус «Сохранено» только после подтверждения сервера. При сбое выбор остаётся в черновике профиля.
4. При конфликте основная — сохранённая серверная версия. Черновик не переписывает её автоматически; применение отдельной кнопкой. Не потерять ни выбор, ни текущие данные.
5. Состояния оборудования: Есть / В СТО / Арендую / Нужно купить. Последнее не означает наличие.
6. Наличие инструмента не доказывает квалификацию. Сначала услуги и условия, затем проверенные возможности оборудования.
7. Один смысл новых карточек — один ID иконки. Шапку, меню и их значки не менять. Использовать существующий логотип.
8. Не создавать копии услуг, каталога, маршрутов, identity или API wrappers. Исследовательские snapshots не редактировать как runtime source of truth.
9. Сохранить текущие 5 шагов клиентской заявки и 4 мастерской. Круги окна настройки локальные.
10. Проверку устройств пользователь берёт на себя; агент делает source/доступные технические checks и явно пишет пределы проверки.
