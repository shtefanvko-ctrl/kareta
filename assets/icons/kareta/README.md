# KARETA semantic registration SVGs

Original 24x24 outline icons supplement the existing `KaretaUIIcons` and Tabler 3.48.0 sprite, not replace them.

| User-facing direction | File | Intent |
|---|---|---|
| Клиент | `client.svg` | Search, booking, car ownership |
| Автосервис | `auto-service.svg` | STO / garage / workshop |
| Автоуслуги | `auto-services.svg` | Mobile and individual automotive service |
| Автотовары | `auto-goods.svg` | Parts, accessories, shop |

No runtime wiring in this PR. Visual compatibility and route binding remain separate tasks.
See `docs/design/KARETA_BRANDBOOK_V3.md` and `css/next/icon_standard.css`.
