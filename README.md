# Kareta CRM и сайт колледжа

Политехнический колледж «Карета» теперь имеет единый репозиторий с презентационным сайтом и CRM на FastAPI.

## Структура проекта

- `backend/` — FastAPI-приложение с базой SQLite и API для программ, студентов и заявок.
- `frontend/` — статический сайт с лендингом колледжа и CRM-панелью для приёмной комиссии.
- `tests/` — автоматические тесты API (pytest).
- `requirements.txt` — зависимости Python.

## Быстрый старт

1. Создайте и активируйте виртуальное окружение Python 3.11+.
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустите сервер:
   ```bash
   uvicorn backend.main:app --reload
   ```
4. Откройте сайт колледжа: `frontend/index.html` (можно через Live Server/serve).
5. CRM-панель находится в `frontend/crm.html`. В поле API URL укажите адрес сервера (по умолчанию `http://localhost:8000`).

## Возможности API

- `/programs` — CRUD по учебным программам.
- `/students` — учет студентов и их статусов.
- `/leads` — заявки абитуриентов, конвертация в студентов.
- `/dashboard/summary` — основные показатели для дашборда.

## Тестирование

```bash
pytest
```

Тесты используют отдельную базу `test_kareta.db`, которая очищается автоматически.
