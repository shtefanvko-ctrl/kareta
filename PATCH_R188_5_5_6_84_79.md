# R188.5.5.6.84.79 — Recovery Merge

Purpose: converge the audited 84.76/84.78 mixed release branch without regressing the 84.77 Tow/Garage and 84.78 Vehicle/Chats UI work.

## Fixed

- `inc/asset_version.php` and `sw.js` are converged to `188.5.5.6.84.79`.
- Existing-account re-login is restored: an authoritative anonymous server session clears stale local onboarding `DONE` state and reopens login.
- Phone verification is phone-first. Existing accounts sign in after OTP; new numbers ask for the missing name only after phone ownership is proven.
- Identity Core is used as a fallback when an existing account lost its legacy `users` projection; the projection is repaired after OTP verification.
- A secondary Identity/context hydration failure is fail-soft after successful OTP/session establishment and no longer turns a valid login into `identity_session_issue_failed` HTTP 500.
- Temporary commissioning OTP remains `0000` in production until explicitly disabled with `KARETA_OTP_TEMP_STATIC_ENABLED=0`. Real-provider mode stays fail-closed.
- Commissioning `0000` bypasses historical per-phone/IP challenge counters while retaining the named concurrency lock; normal provider mode keeps rate limits.
- Production runtime DB migration is fail-closed. It requires the explicit maintenance flag `KARETA_DB_RUNTIME_MIGRATION_WINDOW=1`.
- `config.private.php` is excluded from release packages.
- Release gate now checks current invariants, release parity, migration-manifest integrity, protected files, syntax, and focused regressions 84.65–84.79.
- The 84.79 version convergence helper stages both version files before commit and rolls back if the pair cannot be committed.

## Frozen / protected

- `index.php` unchanged.
- `js/next/smart_action_hub.js` unchanged.

## Deployment

Prefer the full `NO_ASSETS` 84.79 archive if the server currently reports mismatched 84.76/84.78 tokens. `config.private.php` must remain server-local and must not be copied from a release archive.

Temporary OTP `0000` is an intentional commissioning mode and should be disabled immediately when the real SMS provider is connected.
