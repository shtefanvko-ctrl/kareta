# KARETA.KZ R188.5.5.6.84.98

## Исправлено

- `js/next/pages/request.js`: исправлен `ReferenceError: time is not defined` при отправке клиентской заявки. Значение времени теперь считывается из `[data-booking-time]` перед формированием `notes` и payload.
- `js/next/api_client.js`: добавлен общий шлюз для GET-запросов к `api/db.php`: последовательный старт с минимальным интервалом 300 мс и один безопасный повтор при HTTP 429 с учетом `Retry-After` (до 3 секунд).
- POST/мутации не повторяются автоматически, поэтому риск двойного создания/изменения записей не добавлен.
- Версия assets поднята до `188.5.5.6.84.98`.

## DoD

- Отправка заявки больше не обращается к необъявленной переменной `time`.
- Параллельные DB-read запросы не создают стартовый burst на `api/db.php`.
- HTTP 429 на чтении получает один controlled retry; бесконечных циклов нет.
- Синтаксис измененных JS/PHP проверяется перед сборкой архива.
