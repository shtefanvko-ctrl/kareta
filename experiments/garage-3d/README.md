# KARETA.KZ · 3D-гараж (изолированный прототип)

Отдельный статический модуль для разработки мобильной 3D-сцены, не включённый в текущий пользовательский роутинг и не использующий живые API.

## Запуск
Соберите `viewer.bundle.js` командой `npm ci && npm run build`, затем откройте `/experiments/garage-3d/index.html` через локальный HTTP-сервер из корня KARETA (`python3 -m http.server 8080` для локальной разработки, не для продакшна). `file://` не поддерживается из-за загрузки GLB.

## Возможности
- 6 проверенных GLB автомобилей с вращением, зумом и сенсорным управлением.
- Настоящий логотип KARETA из `../../assets/onboarding/kareta_logo_icon.png`; палитра KARETA Orange #FC6606, Graphite #474747, White #FFFFFF.
- Выбор групп геометрии кузов/колёса по фактическим mesh/node names.
- UI-режимы «Кузов», «Электрика», «Механика» и отдельные списки симптомов.
- Экспорт **локального** JSON-черновика с `submitted:false`. Экспорт не создаёт живую заявку. Ссылка на действующий `#/orders/new` ведёт отдельно.

## Ограничения
- Исходные Kenney GLB: стилизованные автомобили; кузов чаще одна mesh-группа. Отдельных крыльев, панелей, двигателя, электросхем и ЭБУ нет.
- Графический движок Three.js; WebGL2. При отсутствии WebGL2 доступна форма выбора услуги без 3D.
- Не подменять Kenney-модель названием/характеристиками Peugeot/BMW; считать только универсальной демонстрационной геометрией.
- Не сообщать о «считанных ошибках» OBD, не делать фиктивные привязки к реальным системам авто.
- Этот прототип нельзя объявлять опубликованным в KARETA production до отдельного merge, QA, release provenance и живой проверки.

## Лицензии и происхождение
9 GLB из Kenney Car Kit (CC0 1.0): `https://kenney.nl/assets/car-kit`. Конверсия GLB: `https://github.com/Hidencod/tge-assets`, также CC0. Подробный `models-manifest.json` хранит ссылки и SHA-256 всех файлов. Bundled JS включает Three.js (MIT) и зависимости через npm. Локальный движок Abyssal Garden (MIT) хранится **вне** KARETA repo: `/home/karetadmin/kareta-external/abyssal-garden`, не вшит и не перепутан с Three.js.
