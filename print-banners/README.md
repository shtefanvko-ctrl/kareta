# Print banners

Production navigation banners for KARETA.KZ.

Files:
- `banner-01-direction.svg` — direction only.
- `banner-02-200m.svg` — direction + 200 metres.
- `banner-03-300m-corner.svg` — 90° turn + 300 metres.
- `RULES.md` — immutable design/QA contract for this banner set.

All three masters are 1000 × 600 mm and contain the exact production KARETA.KZ PNG logo embedded in the SVG.
