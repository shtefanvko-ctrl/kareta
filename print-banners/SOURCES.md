# KARETA.KZ — Print Banner Asset Sources

## Rule
Automotive marks are raster-only in the final banners. No vehicle-brand SVG is embedded in the finished artwork.

## Automotive marks
- BMW — official BMW artwork, rasterized unchanged to `assets/brands/bmw.png`:
  https://www.bmw.dk/content/dam/bmw/common/images/logo-icons/BMW/BMW_Grey-Colour_RGB.svg.asset.1756199978277.svg
- Peugeot — official Peugeot raster artwork, stored as `assets/brands/peugeot.png`:
  https://www.peugeot.com/content/dam/peugeot/master/home/peugeot-logo.png
- Mercedes-Benz — official Mercedes-Benz artwork, rasterized unchanged to `assets/brands/mercedes-benz.png`:
  https://www.mercedes-benz.com/logos/mb-star-white.svg
- Audi — official Audi Media Center raster artwork, stored as `assets/brands/audi.jpg`:
  https://uploads.audi.com/system/production/media/116125/images/74022a65b478f7b3a8e0bf8ba70994f66fde5dd7/A231415_web_2880.jpg
- Volkswagen — official Volkswagen raster artwork, stored as `assets/brands/volkswagen.png`:
  https://www.volkswagen.ch/etc.clientlibs/clientlibs/vwa-ngw18/ngw18-frontend/apps/resources/statics/img/vw-logo-2x.png

## KARETA.KZ
Use only `assets/onboarding/kareta_logo_full.png`. It is not redrawn, recolored, cropped, or replaced.

## Store badges
- Google Play: official Google Play badge artwork.
- App Store: official Apple App Store badge artwork, rasterized to PNG for the print package.

## Prohibited
Font Awesome, generic icon packs, homemade SVG paths, traced vectors, generated look-alikes, unofficial recolors, and distorted third-party logos are prohibited.

Brand-hosted artwork does not by itself settle every commercial trademark-use permission. Confirm the intended signage use before production printing.
